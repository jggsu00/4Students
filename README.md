# 4Students

This application will have two users, one being the tutor and the other being the student. The tutor will be able to create a QR code for each session that they host to allow students to check in. Once students have used the QR code, the tutor will be able to see the attendance data. Students will be able to check in to their tutoring session using a QR code that has been generated by the tutor. On the application, students will see information that is related to the session(s) that they have. This would include tutor information, session time, and subject. Both students and tutors will receive push notifications about any upcoming sessions they have and check-in times. They will also be able to use the app without an internet connection. 

The objective of the tutor will be to create a QR code that allows students to check in and see attendance data that is relevant to the session that the tutor hosts. The student’s objective is to be able to see any relevant session information and to check in for the session. Overall, this application is targeting tutors who are tutoring college students who need a way to organize a session they host, for their students to find it easily.
